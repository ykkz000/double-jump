# Double Jump
This is a mod that enable you to perform a double jump in Minecraft.
## Dependencies

1. A Java Runtime Environment, `>=25`;
2. Minecraft: Java Edition, `>=26.1-`;
3. Fabric Loader;
4. Fabric API;
5. [Mod Menu](https://github.com/TerraformersMC/ModMenu);
6. [Cloth Config](https://github.com/shedaniel/cloth-config).

## Setup
### Setup for gaming

Put the jar file into the `mods` directory.

### Build from sources
#### Building dependencies

1. JDK, `>=25`.

#### Build

On Linux/macOS, use`./gradlew build`. 

On Windows, use `./gradlew build`.
